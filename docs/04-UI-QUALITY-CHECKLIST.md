# UI Quality Checklist

Use this checklist before considering a page complete.

## Visual Accuracy

-   [ ] Layout matches the reference.
-   [ ] Sidebar matches the reference.
-   [ ] Header matches the reference.
-   [ ] Page header matches the reference.
-   [ ] Card dimensions are consistent.
-   [ ] Spacing is consistent.
-   [ ] Typography is consistent.
-   [ ] Colors match the reference.
-   [ ] Borders match the reference.
-   [ ] Border radius matches the reference.
-   [ ] Shadows match the reference.
-   [ ] Icons are appropriate and correctly positioned.
-   [ ] Buttons match the reference.
-   [ ] Tables match the reference.
-   [ ] Filters match the reference.
-   [ ] Charts match the reference.

## Functional UI

-   [ ] Search behaves realistically.
-   [ ] Filters behave realistically.
-   [ ] Pagination works where present.
-   [ ] Sorting works where present.
-   [ ] Row actions work where present.
-   [ ] Dialogs work where present.
-   [ ] Loading states exist where appropriate.
-   [ ] Empty states exist where appropriate.

## Responsive

-   [ ] Desktop layout is correct.
-   [ ] Laptop layout is correct.
-   [ ] Tablet behavior is acceptable.
-   [ ] Mobile behavior is acceptable.
-   [ ] No unwanted horizontal overflow.
-   [ ] Sidebar behavior is correct on smaller screens.

## Architecture

-   [ ] Mock data is separated from presentation.
-   [ ] Components are reasonably reusable.
-   [ ] No giant page component.
-   [ ] No unnecessary duplication.
-   [ ] TypeScript types are used.
-   [ ] Axios is centralized.
-   [ ] Router is structured correctly.
-   [ ] Pinia is used only where appropriate.
-   [ ] Vue Query is configured correctly.
-   [ ] Future API integration will not require rebuilding the UI.

## Design Discipline

-   [ ] No unrequested features were added.
-   [ ] No generic Vuetify dashboard styling replaced the reference.
-   [ ] No unnecessary redesign was introduced.
-   [ ] The approved Dashboard/Home page remains the visual baseline.
