# Design Analysis Instructions

Before writing implementation code, carefully inspect the attached
design/reference.

## Analyze First

Identify:

1.  All pages/screens.
2.  Global application layout.
3.  Sidebar/navigation structure.
4.  Header structure.
5.  Page headers and toolbars.
6.  Reusable components.
7.  Cards and statistics.
8.  Tables.
9.  Filters.
10. Forms.
11. Dialogs.
12. Charts.
13. Status indicators.
14. Empty/loading states.
15. Responsive behavior.
16. Colors.
17. Typography.
18. Spacing.
19. Borders, radius, and shadows.
20. Icon usage.

## Analysis Output

Before implementation, provide a concise analysis containing:

-   Pages identified.
-   Global layout.
-   Reusable component patterns.
-   Visual/design system observations.
-   Dashboard/Home page structure.
-   Any assumptions or ambiguities.

Do not implement the complete application immediately.

## Design Fidelity

The reference design takes priority over default Vuetify styling.

Pay close attention to:

-   Dimensions
-   Alignment
-   Spacing
-   Font sizes and weights
-   Colors
-   Backgrounds
-   Card styling
-   Border radius
-   Shadows
-   Icons
-   Table styling
-   Button styling
-   Filter controls
-   Responsive behavior

Do not replace a distinctive design pattern with a generic Vuetify
equivalent simply because Vuetify provides one.

## Avoid Unrequested Additions

Do not invent:

-   Extra dashboard widgets
-   Extra actions
-   Extra filters
-   Export functionality
-   Notifications
-   Bulk actions
-   New navigation items
-   New business features

unless they are clearly present in the reference or explicitly
requested.
